# Bounded offline execution

`onecli.sandbox.bounded.run_bounded_shell` is an opt-in component for embedding applications; the Agent and CLI do not call it on their own. Its source and staging directories and requested artifact paths must be selected by trusted calling code. Source/staging must be canonical dedicated disjoint directories and remain frozen against concurrent writers. The installed Python/bootstrap, systemd user manager, kernel and read-only `/usr` are trusted.

The host copies at most 8 MiB and 2048 regular single-link source entries into a private read-only input snapshot. A bubblewrap user, PID and network namespace copies that input into `/workspace`, a tmpfs bounded to 16 MiB by default (1–32 MiB allowed). There are no writable host mounts or automatic source writebacks. The root is remounted read-only; no home directory, `/etc`, credentials or network are provided. `/dev` anonymous storage is charged to the aggregate memory control; workspace file storage also has the separate tmpfs bound.

`sandbox_quota` admits the bootstrap only after checking cgroup memory/swap/process/CPU controls. Default aggregate memory is 256 MiB, process count 32 and CPU rate 25%. Worker time is at most 30 seconds; the parent has bounded setup/cleanup allowance. CPU quota is a rate rather than a cumulative CPU-seconds counter; finite wall runtime bounds consumption. Every error cleans up the unit before caller output is parsed. An unavailable quota backend fails closed.

The shell and its output are untrusted. The worker bounds command output to at most 64 KiB, kills other visible namespace processes, and exports only caller-requested regular single-link files through descriptor traversal rejecting symlinks. Up to 32 explicit artifact paths and 1 MiB aggregate bytes are supported. The host treats even the worker JSON as adversarial: it bounds its pipe, validates exact schema/types/path allowlist and decoded sizes, and returns bytes for review, never filesystem writeback. A hostile command can disrupt or spoof the worker protocol, so these results are not an authenticated report that a test passed. Application review must validate artifacts and claims independently.

`BoundedSandboxResult` contains `returncode`, UTF-8 replacement-decoded `output`, `artifacts: dict[str, bytes]`, `timed_out`, and `output_limited`. Aborted runs export no artifacts. Unsafe or absent requested files, malformed protocol, and provisioning failures raise errors. Source snapshots are removed after completion. Untrusted output must not be subsequently interpreted as executable application instructions.

This component does not check provider prices, select masks, authorize model tool use, or defend against hostile privileged or concurrent host mutation. It does not certify kernel-level isolation against kernel exploits. Tests exercise bounded real subprocesses without provider traffic.
